# DVSK Hybrid v0.3 — 产品规约（评审草案）

版本：0.3-draft｜日期：2026-10-17｜状态：待评审，不等于代码已实现

## 1. 产品定位及边界
DVSK 是视觉语义理解与设计规约引擎。首发产品为 HTML PPT 工作台：用户用自然语言或公开/获准的参考图表达审美意图；云端解释、给出候选与样例、生成通用页面架构与参数化布局；企业本地端仅处理私有内容、数据绑定、图表计算、渲染、验收与发布。

**硬约束**：联网视觉发现、图片解构、布局设计、语义解读和架构设计均在云端；本地只负责企业私有内容处理、数据填充、确定性渲染及审计。用户主动上传图片时必须明确区分公开参考图与企业私有图片；后者默认不得发送云端，除非企业策略及授权允许。断网时不宣称云端智能仍可使用；可以使用已审核的缓存模板离线填充。

## 2. MVP 服务对象与关键工作
- 首选：企业中层管理者为高层制作经营/项目 PPT；设计术语掌握有限，但能快速判断视觉样例好坏。
- 用户目标：一句话得到可见的设计候选；少量点击确认；随后本地使用企业材料完成正式汇报。
- 差异化：**表达—解释—视觉样例—确认—可执行规约**，而非单纯提示词或一次性图片生成。

## 3. MVP 用户旅程
1. 用户选择任务类型（经营汇报、项目汇报、方案建议）或直接输入一句话，例如“5 个模块像花瓣一样展开，略有悬浮感”。
2. 云端解析视觉意图，返回 2–4 个**候选**（术语、通俗解释、适用条件、缩略示意、推断/确定性标记）。候选不是事实。
3. 用户选择、混合或拒绝候选；系统仅在重大歧义影响执行时问一个高价值问题。
4. 云端生成不含真实业务内容的页面结构、布局参数及槽位规格；用户预览采用**虚拟内容**。
5. 本地 Gateway 验证签名/版本/Schema/组件白名单；本地内容源映射槽位、渲染、自动检查溢出；用户可修改。
6. 本地导出和发布；可匿名回传用户主动允许的结构性反馈，不默认上报内容或截图。

## 4. 首期范围（P0）
- 自然语言描述→布局术语候选；覆盖至少 20 个实际可渲染的布局模式；语义词典可多于可执行布局库，严格区分。
- 候选样例选择与组合；输出结构化 Visual Semantic Contract、Content Shape Contract 和 Render Contract。
- 单页及 3–5 页演示稿的页面架构建议；第一批任务模板：经营回顾、项目进展、管理决策。
- 可编辑 HTML PPT 和本地填充；本地文本长度与图表约束检查；溢出时安全降级。
- 支持公开参考图的云端解构及对照词典；用户私有图通过清晰授权和出站门禁处理。
- 动态词典最小闭环：人工触发搜索→来源登记→候选去重→审核→发布版本；不把自动采集等同于自动发布。

## 5. 明确不做（P0）
- 训练自己的基础模型；全自动全天候爬取所有设计网站；绕过站点授权保存图片；全面设计软件替代；跨领域视频渲染；专家判断市场；组织级认知资产交易；用户私有资料的云端语义推理。
- PPTX 原生全保真双向编辑；第一版以 HTML 演示为正式交付（是否导出 PPTX 另立专项）。

## 6. 视觉语义词典的对象
每条条目包括：stable_id、规范中文名、英文检索词、用户表达别名、分类、几何/关系特征、可观察证据、适配内容形状、反例/禁忌、实例与授权信息、来源、置信/验证状态、版本、renderer_support。
- `candidate`：模型/网页/上传图提出的待核项；`reviewed`：专业定义及证据审核；`published`：进入可检索正式词典；`renderable`：具备可测试映射和兼容渲染器；`deprecated`：废弃但保留溯源。
- **术语不等于模板**：如“扇形放射”为概念，`radial-card-v1` 为具体可渲染模板。

## 7. 数据分类与隐私默认值
- PUBLIC_REFERENCE：公开或明确授权上传的设计参考，可云端处理且记录来源与许可。
- ABSTRACT_SHAPE：无私有文字、数值、标识符的结构描述；经 Gateway 审核后可出站。
- PRIVATE_CONTENT：企业文字/表格/报告/图表数据；不得出站。
- RESTRICTED：商业秘密、个人信息、敏感字段；默认本地处理；抽象结构也需重识别风险评估。
- 若云端请求真实数据以消除布局问题，应拒绝，改为本地缩排、分栏、换模板或请用户本地确认。

## 8. 验收指标（拟定门槛，基线试验后调整）
设计 30 条覆盖模糊措辞、图像、多块长文案、复杂数据的任务；同任务比较“直接向通用模型请求”和“DVSK 语义层”。独立评价，不允许模型自评作为唯一判据。
- ≥90% 有效输入获得至少 2 个可解释、可区分候选；0 个专业词伪装为用户已确认意图。
- ≥95% Contract 满足 Schema 并进入确定性验证；不合法则 fail-closed，禁止进入渲染。
- 20 个可执行布局均通过固定短/中/长占位文本集的自动版式测试；严重溢出/覆盖不得发布。
- 0 次未授权私有内容出站（以拦截测试及网关日志验证）。
- 首次接受率、满意度、澄清交互次数、完成时间、返工次数用 A/B 试验统计；不预先宣称提升幅度。

## 9. 开发完成定义 DoD
可演示“用户模糊描述→3 个术语/示例→用户确认→云端生成参数化架构→本地使用虚拟/私有数据绑定→HTML 演示→版式自动检查”；提供追踪 ID、Contract 版本、测试报告及失败处理。
