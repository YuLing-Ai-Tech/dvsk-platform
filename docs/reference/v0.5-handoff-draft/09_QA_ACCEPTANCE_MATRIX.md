# QA 与验收矩阵

| 关口 | 自动验证 | 人工审查 | 禁止的假阳性 |
|---|---|---|---|
| M0.5 | pnpm validate/build、43/43 PPT、Python pytest、12页几何、秘密扫描、固定依赖检查 | 候选与 main 差异、版本清单、像素 5/4 原因、敏感文件排除 | 以 macOS Chrome155 截图覆盖 Linux/Chrome154 baseline |
| M1 | JSON Schema 正反例、恶意参数、版本兼容、Adapter 回归 | 数据分类、出站白名单、模板注册表、状态机 | 模型自行提供 sha256/签名被视为可信 |
| M2 | 模糊描述固定集、UI 组件与无障碍、候选状态 | 样例是否真正近似用户意图、术语解释是否误导 | 自动预测被当作已确认 |
| M3 | 三组长度变体、渲染几何、HTML escaping、CSS 注入、QA | 实际展示、未支持布局的诚实 fallback | 长文静默截断 |
| M4 | 图像输入边界、去重、版权字段、版本/回滚、注入测试 | 候选是否有来源与必要许可、人工确认新概念 | 自动把网络发现当正式词典 |
| M5 | Gateway deny-by-default、日志泄漏检查、无真实数据集成 | 客户部署边界、故障和回滚演习 | 私有内容出站后再“去标识” |

**证据包**：`commit_sha`、命令、stdout 摘要、OS/浏览器/字体/依赖版本、失败清单、Golden 差异图/路径、PR 链接、回滚步骤。受保护材料和真实数据不可放在公开 issue/CI artifact。

## 建议 MVP 样例评价集
20+ 自然语言描述：花瓣/扇形/辐射/环绕/分层悬浮/Z路径/瀑布流/左右比较/时间轴/密集数值等，并加入近义及互相矛盾的例子。每例由 Architect 标注允许的候选集合与不可混淆概念；不要只用模型自评当真值。
